# SubLab

자막 번역 · 변환 · 검수

해외 자막을 한글로 번역하고, 프리미어에서 뽑은 텍스트를 SRT로 바꿉니다.
어느 쪽이든 **「한국어 자막 제작 사양」 기준으로 검수**합니다.

## 두 갈래로 씁니다

**A. 해외 자막 번역** — SRT · STL(EBU) 을 넣으면 한글로 번역합니다. Anthropic API 키가 필요합니다.

**B. 프리미어 텍스트 변환** — 프레임 타임코드 텍스트(`00:01:33:18 - 00:01:42:01`)를
SRT 로 바꿉니다. **API 키 없이** 됩니다.

둘 다 같은 검수를 거쳐 같은 형식으로 나옵니다.

## 실제 작업 흐름

```
해외 자막(중국어·영어)
   ↓  SubLab — 번역 + 검수
프리미어 작업
   ↓  SubLab — 변환 + 검수
납품 (본편 SRT · 서브 SRT)
```

## 검수 기준

「한국어 자막 제작 사양」 03·04 와 같은 값입니다. 글자 수는 공백과 태그를 빼고 셉니다.

| 항목 | 기준 |
|---|---|
| 한 줄 | 13자 |
| 읽기 속도 | 초당 9자 |
| 노출 시간 | 1~6초 |
| 최대 줄수 | 2줄 |
| 큐 간격 | 제한 없음 (겹치지만 않으면 됨) |

표기는 세 부호뿐입니다.

- `" "` 영화 제목
- `' '` 고유명사 · 속마음 · 인용
- *기울임* 장소 · 방향 · 시간 · 인물 소개 · 통신 · 화면 밖 목소리 · 화면에 적힌 글자

이 밖에 마침표 · 부호 겹침 · 3인칭 대명사 · 맞춤법 · 공백 누락도 함께 검사합니다.

## 프리미어 텍스트의 함정

프리미어 텍스트 내보내기는 **줄바꿈을 버립니다.**

```
이 자식아, 그딴 거로내 사촌 유혹하지 마
                  ↑ 원래 여기가 줄바꿈
```

검수에서 「공백 누락 의심」과 「13자 초과」로 잡힙니다.
프레임레이트는 **시퀀스 설정과 반드시 같아야** 합니다 — 02 전처리에서 고릅니다.

마지막 자리가 60 이상이면 프레임일 수 없으므로 이미 SRT 로 보고 타임코드를 그대로 씁니다.
